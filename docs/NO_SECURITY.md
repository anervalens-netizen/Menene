# Politica fără securitate

Mehene este o aplicație personală folosită exclusiv de un copil supravegheat.

## Decizie obligatorie

- aplicația nu folosește PIN, parolă, autentificare, biometrie, cod parental sau blocare a meniului;
- meniul de administrare se deschide prin 5 atingeri pe siglă doar pentru a nu aglomera interfața copilului;
- gestul ascuns nu este și nu trebuie prezentat drept mecanism de securitate;
- datele locale nu sunt criptate special de aplicație;
- nu se vor adăuga ulterior mecanisme de securitate fără o cerere explicită a proprietarului proiectului.

Kiosk-ul Android are exclusiv rolul de a simplifica interfața și de a împiedica ieșirile accidentale. Nu este proiectat să protejeze tableta împotriva unui utilizator intenționat sau nesupravegheat.
